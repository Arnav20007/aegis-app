# Emergency Response Platform

Phase 1 and Phase 2 planning for a women safety and emergency response system.

## Planned Stack

- Frontend: React + TypeScript
- Backend: FastAPI (Python)
- Database: PostgreSQL
- ORM: SQLAlchemy
- Authentication: JWT
- Maps: Leaflet + OpenStreetMap
- Deployment: Docker

## Folder Layout

- `frontend/` - React app
- `backend/` - FastAPI app
- `database/` - migrations and seed data
- `docs/` - design notes and project documentation

## Current Status

- Base repository skeleton created
- Frontend and backend scaffolds will be added next
